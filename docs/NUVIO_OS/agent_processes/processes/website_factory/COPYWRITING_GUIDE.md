# Copywriting Guide

## Purpose

This guide controls Stage 7 copywriting. It keeps copy practical, specific, and aligned with the approved page structure.

## Copywriting Pass Rules

- Replace placeholder/source copy only during Stage 7.
- Preserve approved layout and section order unless copy reveals a blueprint issue.
- Do not use copy to introduce unapproved services, integrations, or promises.
- Record unresolved questions in `COPY_DECK.md`.
- Keep CTA labels consistent.

## Before / After Constraints

Before Stage 7:

- blocks may contain source/demo text;
- copy should not be treated as final.

After Stage 7:

- every visible section should have site-specific copy;
- claims should be supportable;
- CTAs should be clear;
- unresolved copy questions should be listed.

## Business-Outcome Tone

Prefer:

- concrete outcomes;
- operational clarity;
- trust and conversion language;
- practical next steps;
- direct explanation of what the visitor gets.

Avoid:

- vague transformation claims;
- enterprise SaaS jargon;
- "AI-powered" filler unless real and relevant;
- guaranteed leads, rankings, bookings, or revenue;
- invented proof.

## Portuguese-First But Adaptable

For Portuguese businesses, copy SHOULD be planned Portuguese-first unless the project brief says otherwise.

Keep meaning adaptable:

- avoid idioms that fail translation;
- record source language;
- keep CTA intent consistent across languages;
- do not mix languages in final UI unless the site is intentionally bilingual.

## Page-Level Copy Structure

Home:

- clear promise;
- practical problem;
- what the business gets;
- how it works;
- proof/preview if real;
- CTA.

Services:

- what is delivered;
- why it matters;
- what is included;
- how delivery works;
- CTA.

Contact:

- why to contact;
- what to send;
- what happens next;
- reassurance;
- CTA.

## CTA Copy Rules

- Use action-oriented labels.
- Do not use vague labels like "Learn more" when a specific next step exists.
- Match CTA destination.
- Do not overuse urgent or manipulative language.

Good examples:

- Request a website review
- See services
- Book a consultation
- Send your project details

## Common Copy Mistakes

- Promising guaranteed lead volume.
- Writing for investors instead of small business owners.
- Naming internal modules before explaining visitor value.
- Making every section a sales pitch.
- Using source block copy because it sounds polished.
